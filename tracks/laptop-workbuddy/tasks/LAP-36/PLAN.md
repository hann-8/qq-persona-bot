## 2. 非目标及不变边界

首版网页以公共静态HTML/text为准；不加浏览器/Playwright、爬站、登录墙绕过、PDF/Office解析、整站索引或向量库。B站只读字幕，不装FFmpeg/Whisper/ASR/音视频模型，不下载音视频、不读取评论/弹幕/封面、不用标题/简介/平台AI摘要替代正文。无字幕ASR仍是LAP-07未完成需求。

不增任何付费模型API、自动后端/模型/账号切换、CLI工具或MCP；仍由现有CodeBuddy CLI/SSH Ollama所选路线生成。原生窗口、思考参数、credits与token/UTF-8字节分别说明，不承诺免费或精确上游API次数。图片理解与发受控表情是独立开关。

授权群、黑名单前置、私聊关闭、mentions/free当前合同、真实@优先、LAP-35哑巴/代际栅栏、冻结目标、一次尝试、同链ACK/unknown恢复保持。不得通过引用/转发补拉历史图片、链接或被屏蔽作者；首版只使用本次已准入消息的图片/可见文字链接。后台没有定时主动任务。

## 3. 决定采用的路线及开源取舍

1. 图片继续复用LAP-28，不另装OCR/识图服务。OneBot收到image段及可下载URL就是有效附件入口；二进制在受控下载后进入内存，不能要求JSON帧本身一定内嵌base64。只看到`[图片]`的字符串则不构成图片输入。
2. 网页使用`readability-lxml==0.9`的本地Document正文提取，不调用其下载CLI；HTTP仍由项目安全传输负责。相较trafilatura，选取范围更小，不引入其日期/语言/爬虫依赖；Defuddle/Mozilla Readability是候选，不并装Node正文栈。中文/文档页质量必须本项目验证，仓库自述成绩不算通过。
3. B站复用yt-dlp固定提交`897341241f2bfb2439fe0367f4c7c9ccd29a3828`中Bilibili字幕端点/字段处理的最小片段，附Unlicense和来源记录；仅保留单轨字幕枚举/解析，将下载回调接到项目PublicHTTP。不得整包开启`extract_info`、下载器、全部字幕、评论或播放地址流程。具体适配差异见网页/B站合同。
4. 当前`Nemo2011/bilibili-api`公共仓库已归档且源码入口404，不能照旧教程安装；继任候选bilibili-api-zoku涵盖大量其他API且依赖更广，首版不选。调研的AstrBot插件另接模型API或开启转写/评论/卡片/引用解析，不原样安装。不是重新做B站播放器/爬虫，只补本项目必须的权限、限额、来源和ACK包装。

以上包/源版本为本轮核对快照；medium应验证固定源及许可证可取得，锁定依赖和哈希。不能改成浮动latest，也不能发现缺口后悄悄换依赖/服务。

## 4. 共用架构与生效方式

```text
NapCat array事件 → gate授权/黑名单/哑巴控制 → 当前目标/材料证明
  图片：image段 → 一次cap → 受控公共下载 → RAM规范化 → 所选runner原生image
  网页：当前文字URL → 受控公共下载 → 本地正文提取 → 有界不可信材料
  B站：当前文字BV/AV/URL → 当前P元数据/单轨字幕 → 有界不可信材料
  → 统一队列/最终预算 → 所选runner最多一次生成 → 现有ReplyPlan/栅栏/ACK
```

图片不先调用另一个模型做caption。网页/B站不先调小模型分类、逐段归纳再合并。长材料先在本地裁选并准确标注范围，不能扩大单次预算。失败提示通过现有BackendResult/ReplyPlan进入同一输出管道，`generation_performed=false`；不另起插件直接send、不多发第二答。ambient失败保持现有沉默策略，真实@按原规则给短说明。

新字段归LAP-34的`config/examples/features.yaml`及同名忽略local文件；旧settings兼容入口保留，loader/旁注/索引/双摘要/快照统一更新。代码与模板交付后仍需操作者关闭、审阅配置、正常启动才生效；不热更新，不迁移/改写真实local或自动启用。字段细表在两个专项计划。

## 5. 必须先解决的网络条件

本轮只读查询五个公共域名，系统DNS均返回非公网地址（每域2条/公网0条）。不能推断是哪一个代理/VPN/网络软件造成，更不能把浏览工具能开GitHub当成本机PublicHTTP可用。本轮两次小型公开DoH诊断均TLS证书失败；带正确域名/SNI且固定公共bootstrap的诊断返回证书验证码20。因此**项目本机安全公共网络尚未证实可用**。

LAP-18续作应增加明确可选的项目内解析模式`system|cloudflare_doh`，默认system；DoH只通过固定域名TLS和固定公共bootstrap，保留所有公网/peer/TLS检查，不自动回退或改全局DNS/代理。可选项目本机CA文件仅用于操作者明确选定的证书信任，默认无；不得下载/信任目标站点提供的自签名CA，不使用verify=false。

这条路线尚未通过本机TLS/正文探测，实施后须用无隐私公开域名和页面核验。仍失败时独立交付提取器、离线/诊断代码并保留network_unverified；不开放私网地址、不换付费读取服务、不循环尝试更多DNS提供方。网页、QQ图片下载和B站JSON共用同一安全传输策略，避免三套网络规则互相绕过。

## 7. 验证与可用性验收

离线验证使用自造图片/公开或合成HTML/自造字幕JSON/本机假端点，分别证明权限、材料、预算、次数、超时取消和同链发送；不得将测试替身成功或手写metadata当真实模型成功。各专项规定受影响实际AstrBot/provider/run_agent/两runner底层替身回归。

真实验证分三类单独授权与登记：公共材料读取（0模型/0群发）；所选后端自造材料原生生成（固定样本/总次数，每例一次，0群发）；指定授权群的用户自造样本/同链ACK（一次最终输出）。真实模型预算不在本轮花费；不自动验证两后端、不重试失败例，不通过新trace绕过失败/unknown台账。

功能可用至少需要：对应材料真通过、所选模型质量通过、最终预算与取消通过、相应输出/来源/ACK真实通过；图片还需可信视觉上界证明。完整第一版仍含原LAP-07 ASR和旧V/O/P等差额，不因轻量字幕阶段交付标完整验收。

## 8. 兼容、迁移、回滚与分支出口

新增配置缺省关闭新能力/沿用system解析；已有web.enabled不被自动改写，原网页触发仍保留，仅增加B站自己的更窄触发。vision.input_reserve_tokens=4096保留兼容，但不具备授信含义，不能靠减值启用。正文/字幕/图片证明进入适当请求manifest及能力绑定，不把瞬时URL/图片base64/cap写进聊天历史或版本键；网络/提取器配置变更进入配置快照/版本，防止旧绑定继续用。
